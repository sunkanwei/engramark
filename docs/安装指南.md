# 安装与升级

**[English](installation.md) | [简体中文](安装指南.md)**

本文面向 Engramark 使用者，说明支持系统、可信安装、升级、目录和卸载。维护者构建发布候选的流程见[维护者发布指南](发布指南.md)。

## 支持的平台

当前发布目标：

| 系统 | 架构 | 原生验证 |
|---|---|---|
| macOS 14/15 | Apple Silicon | macOS 14 与 15 runner |
| macOS 15 | Intel | macOS 15 Intel runner |
| Ubuntu 22.04/24.04 | x86_64 | glibc 2.35 基线与 Ubuntu 24.04 复验 |
| Windows Server 2022/2025 | x86_64 | Windows PowerShell 5.1 与 PowerShell 7 兼容安装 |

只有对应原生 CI 作业完成完整测试、能力探针、打包和安装生命周期后，该次产物才构成受支持版本。交叉编译或二进制声明的最低系统版本不能替代原生运行证据。

## 安装

macOS 与 Linux：

```sh
curl -fsSL https://raw.githubusercontent.com/sunkanwei/engramark/main/install.sh -o /tmp/engramark-install.sh
sh /tmp/engramark-install.sh
```

Windows x86_64，可使用系统自带的 Windows PowerShell 5.1 或 PowerShell 7：

```powershell
$script = Join-Path $env:TEMP "engramark-install.ps1"
Invoke-WebRequest https://raw.githubusercontent.com/sunkanwei/engramark/main/install.ps1 -OutFile $script
& "$env:SystemRoot\System32\WindowsPowerShell\v1.0\powershell.exe" -NoProfile -ExecutionPolicy Bypass -File $script
```

`-ExecutionPolicy Bypass` 只对本次安装子进程生效，不会永久修改用户的执行策略。若单位通过组策略禁止未签名脚本，本命令也不能越过该管理策略，需要设备管理员放行。

安装包是内嵌 SQLite 的单一原生程序，不要求另行安装 Python、Homebrew、数据库或包管理器。

## 安装器会做什么

安装器按以下边界工作：

1. 根据当前系统和架构选择发布包。
2. 校验发布页中的 SHA-256。
3. 拒绝绝对路径、目录穿越、链接、特殊文件、大小写冲突和超量归档。
4. 按包内 `MANIFEST.tsv` 复验条目白名单、大小和逐文件哈希。
5. 运行 SQLite 能力自检和宿主配置预检。
6. 获取安装锁，原子切换程序目录，并保留用于失败恢复的旧版本。
7. 迁移旧卡片、重建派生缓存并执行完整诊断。
8. 以可回滚方式接入检测到的 Codex 与 OpenCode。

任何步骤失败，安装器都会尽力恢复安装前的程序和宿主配置。私人记忆目录不会因安装失败而删除。

## 文件位置

macOS 与 Linux：

```text
~/.local/share/engramark/   可替换的程序
~/engramark/                私人记忆、状态、配置和派生缓存
```

Windows：

```text
%LOCALAPPDATA%\Engramark\   可替换的程序
%USERPROFILE%\engramark\    私人记忆、状态、配置和派生缓存
```

程序和私人数据刻意分开：重新安装只替换程序，不覆盖记忆。

## 下载来源与系统警告

只应从本仓库的 GitHub Releases 或本页官方安装脚本安装。当前公开包提供：

- 发布页 `checksums.txt`，用于发现下载损坏或内容不一致；
- 包内 `MANIFEST.tsv`，用于展开后逐文件校验；
- SBOM 与依赖许可证集合；
- GitHub 构建来源证明，用于确认产物由本仓库工作流生成。

当前公开包没有 Apple Developer ID 签名、公证或 Windows 代码签名。Windows 可能显示“未知发布者”或 SmartScreen 提示；这些完整性与来源措施也不能替代操作系统代码签名。无法确认下载来源时，不应绕过系统警告。

## 升级与重装

升级或重装使用同一条安装命令。安装器会先验证新程序，再切换固定程序目录；如果后续数据准备、冒烟或宿主接线失败，会恢复旧程序和旧接线。

升级完成后请重启 Codex 和 OpenCode。已经运行的旧会话可能继续引用被替换的程序路径，直到宿主重启。

升级不会覆盖：

- `~/engramark/cards/` 中的记忆真源；
- 编号高水位和未决事务等持久状态；
- 用户配置 `engramark.json`。

如果缓存结构或运行时能力指纹发生变化，Engramark 会从文本真源重建派生缓存。

## 验证安装

macOS 与 Linux：

```sh
~/.local/share/engramark/bin/engramark diagnose --full
```

Windows：

```powershell
& "$env:LOCALAPPDATA\Engramark\bin\engramark.exe" diagnose --full
```

完整诊断会检查卡片、编号高水位、SQLite、两个全文索引、语义哈希、源集合哈希和运行时能力。

## 卸载

macOS 与 Linux：

```sh
~/.local/share/engramark/bin/uninstall
```

Windows：

```powershell
& "$env:SystemRoot\System32\WindowsPowerShell\v1.0\powershell.exe" -NoProfile -ExecutionPolicy Bypass -File "$env:LOCALAPPDATA\Engramark\bin\uninstall.ps1"
```

卸载只移除程序和 Engramark 管理的宿主接线，始终保留私人记忆。程序不提供自动删除记忆的参数；确实不再需要记忆时，由用户在确认备份后手工处理数据目录。
