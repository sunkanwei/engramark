# 测试与验收

**[English](testing.md) | [简体中文](测试与验收.md)**

测试保护核心行为和高风险数据边界。全部行为测试使用临时目录，不读取真实记忆。

## 日常测试

```sh
python3 tests/run.py
```

运行器先构建当前源码的调试二进制并通过环境变量固定所有黑盒测试目标，再执行 `cargo test --locked` 和 7 组黑盒测试。它不会因为 `target/release` 中恰好存在旧文件而误测陈旧二进制。

| 测试 | 覆盖范围 |
|---|---|
| 文档 | Markdown 一级标题、相对链接和中英文文件配对 |
| 核心 | 卡片生命周期、结构化 MCP、多语言显式保存规则、项目隔离、反馈、隐私和并发写入 |
| 架构 | 事务恢复、缓存、编号、备份和迁移 |
| Codex | 钩子、微摘要、完整块预算、卡片级冷却、SessionStart 短摘要、不保存会话和失败开放 |
| OpenCode 雷达内核 | 严格协议、单行与完整块预算、临时保留、卡片级耐久冷却、共享锚点隔离、并发、500 条负样本和性能门槛 |
| OpenCode 适配器 | 文本来源、命令跳过、系统块、消息 ID、耐久事件、故障取消和真实内核端到端 |
| 宿主接线 | 两个宿主及 Codex 项目 `cwd` 的重复接线、旧接线升级、最小雷达插件和卸载 |

仓库隐私依赖 Git 元数据，由 CI 单独运行：

```sh
python3 tests/test_repository_privacy.py
```

## 金样

`tests/golden/` 是移植完成时冻结的兼容契约，覆盖规范化、卡片格式、哈希、查询规划、检索、雷达、扫描和错误语义。Rust 测试会先按 `manifest.json` 校验文件集合与 SHA-256，再执行行为断言。旧实现和生成器不再保留；契约变化必须经过明确评审，同时更新对应金样、清单、实现和面向用户的文档。

## 可选规模基准

```sh
python3 tests/test_retrieval_scale.py
```

该脚本默认使用 2,000 张合成卡模拟多年手动积累，检查正确召回、无关拒答、项目隔离、雷达误提示、搜索与雷达延迟和注入字节数。

发布前的 10,006 张非 CI 验收使用同一脚本：

```sh
ENGRAMARK_SCALE_CARDS=10006 python3 tests/test_retrieval_scale.py
```

## 安装生命周期

```sh
python3 packaging/build_release.py
python3 tests/test_install_lifecycle.py
```

在本机原生目标的隔离 HOME 中验证：危险归档拒绝 → 安装 → 接线 → MCP → 钩子/雷达 → 检索 → 写入 → 备份 → 升级重装 → 卸载，且卸载后数据完整。

## 发布检查

CI 的静态门禁包括仓库隐私、文档、Python 测试驱动与 shell 脚本静态检查、Rust 格式与 Clippy，以及依赖漏洞、许可证和来源检查。原生矩阵在 macOS 14/15 arm64 与 x86_64、Ubuntu 22.04/24.04 x86_64、Windows Server 2022/2025 x86_64 分别运行完整 Rust/黑盒测试、最终二进制能力探针、打包和安装生命周期。Linux 发布物在 Ubuntu 22.04 构建，并拒绝高于 glibc 2.35 的符号需求；同一候选包还会在 Ubuntu 24.04 复验。

可选静态检查：

```sh
ruff check tests packaging
shellcheck install.sh bin/install.sh bin/uninstall bin/uninstall.sh
git diff --check
```
